# 一机三卡无需现场训练版交付说明

本分支：codex/frozen-fast-local3x5090-20261103。旧三机分支保持不变。本版入口是 scripts/run_fast3_local.sh，调用 pipeline.fast3 --phase local --gpus 0,1,2；不配置 hosts、不要求 SSH、不经 SCP 回传，也不生成本地 rank 传输压缩包。原三机入口仅为兼容保留，不是本版流程。

只安装一份环境、准备一份模型/数据/已有参数；三个 worker 共享只读材料，各自保留输出、缓存、临时目录和锁。物理卡索引通过 nvidia-smi 解析为 UUID；CUDA 用 UUID 绑定，NVML 与资源核验仍使用对应物理索引，防止 CUDA 与 nvidia-smi 的排序差异。启动前拒绝被占用的卡，不停止任何其他任务。项目内物理 UUID 锁也阻止本项目的两个本机调度器重复占卡。

单机需要能够容纳三个独立模型进程的 CPU、内存和磁盘吞吐。建议 24 核以上、96GB 以上主存、足够的本地 SSD 空间；这是容量建议，不是已有实测速度。模型磁盘文件不复制三份，但各进程 CPU 临时张量、GPU 权重、OCR、视觉缓存仍各自占用资源。

指标1.11/1.12仍只评估 InternVL 的 POPE4500、TextVQA2496 固定测试集；Qwen仅作辅助回答。指标1.13仍为3360请求、四套各840条、五臂和16800逻辑审核。供给参数、BF16模型、采样/验证次数、信号定义、全局ECE、阈值与原安全数学不变。没有启用INT4、熵预测器、现场fit或测试集选参。

Qwen批量64/16，InternVL4/1，安全主生成1。保留精确图像/视觉/前缀缓存、CPU OCR预读、安全热路径开发门控、答案审核去重与长度分桶。审核仍从6/16/32/64中按两轮开发一致性和耗时选择，不把某张A100的32直接写成三张5090均已验证的最优值。

正式入口一次启动三份任务，全部成功后统一评分、审计并自动生成总报告与三个指标报告；任一 worker 失败只留 INCOMPLETE，不生成新的达标结论。原始回执保持不可变，全量合并核对所有ID、尾块和GPU UUID；ECE不是分片ECE的平均。续跑沿用同一命令，不改卡映射、代码或参数；首次启动时间保留在 cluster_origin.json，总墙钟含故障和暂停。本次调用另计于 local3_timing.json。

Word按用户原模板保留命令、成功提示、报告位置；技术边界单列在本说明和审计中。代码ZIP顶层为MSRC/，外部复用材料与env_patch按流程并列放置。新包、GitHub提交、逐文件SHA256、CPU测试统计与网盘下载回读见RELEASE.json及DSH独立回执。

这是带质量门控的候选交付，不是已完成一机三卡全量验收。旧版3.5至5小时仅是三机就绪环境估算，不能直接当作本机三卡实测或承诺；单机CPU、主存、SSD争用须通过实际全程计时确认。没有租新机器、没有启动付费实验、没有改历史结果，也没有访问HLC共享服务器。
