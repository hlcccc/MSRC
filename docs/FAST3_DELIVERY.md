# 三卡无需现场训练版交付说明

本分支在原发布代码外增加 pipeline.fast3、fast3_assets、fast3_contract、fast3_factual、fast3_safety，以及已在单卡开发侧验证的执行优化模块。原冻结安全算法目录逐字节不变。唯一共用代码调整：factual.MODELS只从配置中实际存在的三个事实性角色取值，使限定InternVL流程不再要求配置LLaVA；全角色配置仍保留原行为。

本版追求已知候选中最快且满足开发质量门控的执行，不宣称穷尽所有配置后的全局最快。正式指标只能由新的三卡全量结果判定。审计清单和八步流程须一同交付；请先阅读FAST3_FLOW.md及FAST3_AUDIT.md。

适用：三个独占Ubuntu5090节点，每节点一GPU；第一台协调，另外两台经公钥SSH运行，三个安装路径相同。无需NCCL、DDP或多卡模型切分。每节点依次切换模型，节点间独立流水，不在单卡上同时装多套大模型。

范围：指标1.11/1.12仅InternVL的两个固定测试单元；Qwen是跨模型一致性辅助；指标1.13仍是3360请求、四套各840、五臂、16800逻辑审核。没有把测试集再次减半，也不把旧测试预测当新证据。没有现场fit，也未启用INT4或熵预测器。

速度：环境/模型/数据就绪后的整个新测试流程估计3.5至5小时，含必要开发工程自检、生成、审核、合并评分、审计和报告；未实测三卡，不保证≤5小时。首次下载/搬运/安装另计。精确批量是Qwen64/16、InternVL4/1、安全主生成1；审核按开发两轮结果从6/16/32/64择最快准入项，不能提前伪称全部节点已采用32。

根SHA256SUMS核对本次新代码、文档及env_patch补充依赖；复用模型、原数据与已有参数另按代码内发布配方逐文件核验。GitHub不上传数据、基座权重、运行输出、登录凭据。新网盘目录是代码、文档与小依赖交付，不是把45GB模型复制到ZIP；配套六目录分享直接并列放在发布根目录，来源要看DSH回执，缺材料不可跳过。已租云实例及历史实验均未改动。

固定Git提交、代码ZIP SHA256、回归测试统计、原生/GPU尚未验证边界和DSH网盘回执见本次发布目录的RELEASE.json。上传完成须下载回读一致；未回读的大文件不能写成已验证。本流程不自动新增任何付费资源。
