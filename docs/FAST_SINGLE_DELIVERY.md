# 单卡5090无需现场训练版

本分支codex/frozen-fast-single5090-20261103，基于一机三卡固定提交e0eea8f。入口scripts/run_fast_single.sh，Slurm入口scripts/run_fast_single_slurm.sh。三卡版和三机版原分支、原交付包均不覆盖。

一张物理5090依次执行rank0、1、2三个逻辑分片，保留原全局块及种子。物理卡数量明确记录为1，不冒充三卡并行或三卡速度。模型/材料/环境只一份，不经SSH、SCP或结果tar。完成后自动做同一套全局评分和报告。

保留：Qwen辅助回答批量64/16，InternVL批量4/1，精确图像/视觉/前缀缓存、OCR预读、安全热路径开发门控、答案审核精确去重与长度分桶。审核仍在开发侧两轮从6/16/32/64中选最快合格项，不硬写成32。没有额外启用INT4、熵预测器或现场训练，不减正式测试、采样和五臂审核。

直接运行默认选物理0卡；没有继承CUDA_VISIBLE_DEVICES时，可传--gpu 其他物理索引。继承CUDA掩码（含Slurm）时不传--gpu，脚本先在原掩码内用退出即释放的子进程读取CUDA实际UUID，再对照NVML索引。GPU探测失败、并非单张5090或存在其他计算PID即停止，不杀进程，不自动越出分配范围。重复设备选择也绑定已验证UUID；common.py及供给参数绑定的推理核心不改。

同一run-id续跑需同主机、同物理卡、同代码/参数。Slurm重新分配到不同卡时应换run-id，不把旧结果接成新卡实验。已完成分片只核验旧回执，失败停止后续分片；已有merged不覆盖。报告只有三份完整回执、全量ID和因果事件都通过核验才生成。SCOPED_PASS、SCOPED_FAIL、INCOMPLETE及退出码0、3、4不变。

single_timing.json计入首次启动后的准备、三份串行测试、全局评分、审计和报告；含失败和暂停时间，另记当前调用耗时。初次下载和安装不计入推理入口计时；Slurm日志涵盖作业内安装过程，排队时间须另计。没有此版本完整单卡实测用时，不能承诺五小时或保证最终指标达标。

外层目录可在首次安装前改名，只需同步流程中的cd路径；保持解压后的MSRC项目和六个材料目录相对位置。安装后的.venv及绝对路径配置不应直接搬迁，换位置应重新安装并准备材料。文件名中的日期是发布标识，不需要改成运行当天。每个独立项目目录会创建自己的.venv，无须修改共享Python或Conda环境。

代码包不含大型模型、数据和原离线运行时，继续使用流程列出的原材料网盘。env_patch仍须校验并合并。CPU模拟测试、Word内容核验和归档核验不能替代真实5090及Slurm集群验收，详细边界见逐步审计和RELEASE.json。
