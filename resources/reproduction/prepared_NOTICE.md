# Prepared benchmark data and fixed partitions

This package contains processed input images, questions, reference annotations,
and fixed development/test partitions. It contains no model predictions, test
scores, fitted parameters or base-model weights. Ground-truth reference answers
are annotations, not model-generated answers. Preserve the upstream terms.

- POPE: https://github.com/AoiDragon/POPE (MIT for the benchmark repository).
- COCO 2014 images: https://cocodataset.org/#termsofuse . Individual image
  copyright and original Flickr terms remain with their respective owners;
  the benchmark/repository license does not relicense those images.
- TextVQA validation: https://textvqa.org/dataset/ and
  https://huggingface.co/datasets/lmms-lab/textvqa . Preserve the dataset's
  upstream image/annotation terms and attribution.
- MM-SafetyBench: https://github.com/isXinLiu/MM-SafetyBench and
  https://huggingface.co/datasets/ALM/MM-SafetyBench (CC BY-NC 4.0).
- Benign requests/images: deterministically generated by pipeline/build_benign.py
  from https://huggingface.co/datasets/tatsu-lab/alpaca (CC BY-NC 4.0).
  Their row/image hashes match the public reproduction recipe.

Intended use: noncommercial research and project evaluation, subject to the
upstream terms. This package grants no additional commercial image rights.
The scripts retain a public-source rebuild route for provenance checking.
